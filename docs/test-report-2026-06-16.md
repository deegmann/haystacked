## 🚨 MISMATCH REPORT

### Mismatch 1 — CompanyX.pdf: six fabricated numeric COND_KO values with fabricated supporting "sources" — CRITICAL

**What was expected:** Based on an independent, exhaustive read of `tenders/CompanyX.pdf` (pdfplumber text + table extraction across all 12 pages, with exhaustive substring search), the document states exactly one numeric AGV operating constraint: pallet weight "maximum of 1,000 kg". It contains **no** statement of maximum lift height, operating temperature range, maximum humidity, maximum gradeability, or maximum overall vehicle height. (The only height-like numbers in the document are the optional Concept-Variant-2 cantilever station heights of 2700mm/5400mm, and a floor gradient of "approximately 1.5%" scoped explicitly to "near the loading gates" — neither is a vehicle KO specification.)

**What actually happened:** The pipeline extracted and passed through validation:
- `required_max_lift_height_m = 4.8` — cited source: *"The maximum lift height of the AGVs is up to 4.8 m."*
- `required_temp_min_c = -25`, `required_temp_max_c = 40` — cited source: *"The operating temperature range for the AGVs is from -25 °C to +40 °C."*
- `required_humidity_max_pct = 95` — cited source: *"The maximum relative humidity the AGVs must tolerate is 95%."*
- `required_max_gradient_pct = 10` — cited source: *"The maximum gradeability of the loaded unit is up to 10 %."*
- `required_max_vehicle_height_mm = 2500` — cited source: *"The lowest overall vehicle height (mast collapsed) is 2,500 mm."*

None of these five quoted sentences — nor any of their key terms or numeric values ("4.8", "-25", "+40", "95%", "gradeability", "mast collapsed") — appear anywhere in the actual extracted PDF text. This was confirmed twice, independently, with exhaustive Python substring search against the full 12-page extracted document.

**Root cause:** Pass 4b (batch AGV-criteria extraction) fabricates plausible, well-formed English sentences for fields it cannot find in the document, and presents them as direct quotations with high apparent confidence. The source-span hallucination guard (Layers 1 and 2, described in `CLAUDE.md`) is designed to catch exactly this failure mode, but its check is purely numeric: Layer 1 only requires that a `<field>_source` string be present and non-empty; Layer 2 (`_source_confirms_value()`) only checks whether the numeric value appears (with unit-scale tolerance) inside the cited source string. Neither layer verifies that the cited source string is itself a genuine substring of the source document. Because the LLM's fabricated source sentences are numerically self-consistent (the sentence "is up to 4.8 m" does contain "4.8"), Layer 2 reports a pass, and the hallucinated value survives into the final criteria used for matching.

**Downstream impact on matching:** All 6 fabricated values are COND_KO fields (`KO_IF_LT`/`KO_IF_GT`), so each one independently disqualifies suppliers below/above the fabricated threshold. The qualified count for CompanyX collapsed from an expected ~26 (genuine-constraints-only) to 11 — a reduction entirely attributable to hallucinated criteria, not to genuine tender requirements. Suppliers correctly eligible under the real tender text (e.g. any Forklift AGV with payload ≥1000kg and no VNA requirement) are being silently excluded from a real B2B tendering platform based on requirements the buyer never stated. This is a customer-facing correctness defect, not merely a cosmetic extraction quirk.

**This is not a newly-introduced regression** — historical memory shows this exact same value set (weight=1000, lift=4.8, temp=-25/40, humidity=95, gradient=10, vehicle_height=2500/2700/3000 depending on run) appearing consistently across at least 15+ prior pipeline runs going back to early June, always treated in prior reports as "all KO fields match expectations" because no one had previously cross-checked the cited sources against the actual source document. This test run is the first to establish, by direct document inspection, that the long-standing CompanyX "golden" extraction itself was never grounded in the document text for 6 of its 8 historically-tracked numeric fields.

**Severity: CRITICAL.** This is a systematic, reproducible, document-specific hallucination that defeats the purpose of the source-span hallucination guard for this tender, has been silently passing as "correct" in every historical report and golden-file comparison to date, and directly causes incorrect supplier disqualification in a live matching platform.
